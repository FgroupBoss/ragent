## 2. 前置条件与已知限制

1. **LLM API Key 未配置**：聊天问答、意图识别、文档向量化依赖外部模型。
   未配置 `BAILIAN_API_KEY / SILICONFLOW_API_KEY / AIHUBMIX_API_KEY`（或本地 Ollama）时：
   - 聊天接口会返回"模型调用失败"类错误（预期行为）；
   - 文档分块会在**向量化阶段失败**，文档状态为 `failed`，分块日志能看到
     Parse/Chunk 阶段耗时（预期行为，用于验证入库链路）。
   配置方式：启动后端前设置环境变量，或在 `application.yaml` 的 `ai.providers` 填入 Key。
2. **mcp-server 未启动**（端口 9099）：MCP 类意图的工具调用会跳过/报错，
   其余功能不受影响。
3. 冒烟测试会创建测试数据（知识库/文档），测试后需手动清理或使用脚本自清理。

## 4. 自动化冒烟脚本

仓库提供 [scripts/functional-smoke.ps1](/E:/projects/ragent/scripts/functional-smoke.ps1)，
一键执行核心 API 冒烟（登录 → 会话 → 知识库 → 文档上传 → 触发分块 → 状态/日志 → 清理），
输出逐项 PASS/FAIL。运行方式（PowerShell）：

```powershell
powershell -ExecutionPolicy Bypass -File E:\projects\ragent\scripts\functional-smoke.ps1
```

> 说明：脚本自动创建"冒烟-时间戳"知识库并上传测试文档，验证
> MySQL + Kafka Outbox + MinIO 链路后自动清理；未配置 LLM Key 时，
> 分块用例预期为 `failed`（嵌入阶段失败），脚本按此断言并提示。

## 5. 常见问题

| 现象 | 处理 |
|:---|:---|
| 登录提示未登录/跳登录页 | 确认 Redis 可用且 token 头为 `Authorization` |
| 上传/分块报"系统执行出错" | 查看 `ragent-run.log`；常见为未传 `processMode` 或 MIME 不支持 |
| 分块状态一直 running | 检查 Kafka 消费者是否正常（`kafka-consumer-groups.sh --describe`）与 `t_mq_outbox` 状态 |
| 聊天报"模型调用失败" | 配置对应 Provider 的 API Key 或启动 Ollama |
| MCP 报连接失败 | 启动 mcp-server（`mvn -pl mcp-server spring-boot:run`） |
